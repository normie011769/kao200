chmod [-R] 權限 文件或文件夾  修改權限
(只有文件 文件夾的所屬用戶或ROOT用戶可以修改)
-R 對文件夾內的全部內容應用同樣的操作

ex:chmod u=rwx,g=rx,o=x hello.txt 將文件權限修改為:rwxr-x--x(u=user g=group o=other)
chmod -R u=rwx,g=rx,o=x test 將文件夾test以及文件夾內全部內容權限設置為rwxr-x--x

快速寫法:	    4 2 1 二進位	
chmod 751 test.txt  _ _ _
      		    r w x
		    u g o


chown [-R] [用戶][:][用戶組] 文件或文件夾 (普通用戶無法修改所屬為其他用戶或組 此命令只適用於root用戶執行)
-R:對文件夾內全部內容應用
ex:chown root hello.txt 將hello.txt所屬用戶修改為root
chown :root hello.txt 將hello.txt所屬用戶組修改為root

壓縮格式 linux:tar(.tz) gzip(.gz)

tar [-c -v -x -f -z -C] [PARAMETER 1....]
-c 創建壓縮文件 壓縮模式
-v 顯示壓縮解壓縮過程 察看進度
-x 解壓縮模式
-f 要創建的文件 或要解壓縮的文件-f必須在所有選項中位置處於最後一個
-z gzip模式 不使用-z就是普通tarball格式(處於第一個位置)
-C 選擇解壓縮的目的地 用於解壓縮模式

tar -cvf test.tar 1.txt 2.txt 3.txt -> 表示將1.txt 2.txt 3.txt 壓縮成一個test.tar檔案

tar -zcvf test.tar.gz 1.txt 2.txt 3.txt -> 將1.txt 2.txt 3.txt 壓縮到test.tar.gz文件內 使用gzip模式


解壓縮常用
tar -xvf test.tar
tar -xvf test.tar -C /home/kuo -> 解壓縮test.tar將文件解壓縮至指定目錄
tar -zxvf test.tar.gz -C /home/kuo -> 以gzip模式解壓縮test.tar.gz 將文建解壓縮至指定目錄
-C 單獨使用 和其他參數分開
-f 最後一位
-z 建議放開頭位置


zip [-r] parameter1 .... 可使用zip命令 壓縮文件為zip壓縮包
-r 被壓縮的包含文件夾的時候 需要使用-r選項 和rm cp等命令-r效果相同
 
ex: zip test.zip a.txt b.txt c.txt -> 將a.txt b.txt c.txt壓縮到test.zip文件內
zip -r test.zip test kuo a.txt -> 將test kuo 兩個文件夾和a.txt 壓縮到test.zip文件內

unzip [-d] parameter  解壓縮zip壓縮包
-d 指定要解壓縮去的位置 同tar的-C選項
PARAMETER 被解壓縮的zip壓縮包文件

ex: unzip test.zip 解壓縮test.zip到當前目錄
unzip test.zip -d /home/kuo  將test.zip解壓縮到指定目錄
